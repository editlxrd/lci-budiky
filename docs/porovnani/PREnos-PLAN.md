# Přenos LCI Budíky pro první test v autě

Cíl: vlastní česká aplikace a schválené červené G20 budíky, zapnutí/vypnutí a BC z aplikace. Repozitář na Davidově GitHubu, instalace ze zdrojů přes MGU Store.

1. Oddělený čtecí adaptér a model: živé hodnoty, přesný Sport Individual, UDS BC/EGS, žádné kódování. Test zablokovat bez čerstvých P a nulové rychlosti, při změně podmínek ukončit. První release test na 60 s.
2. Vykreslování: prostředky z GS Dash (ověřený klient, transparentní výřezy, paměť a rendererový dead-man). Konsolidovat původních 11 vrstev nejvýše na 4. Ponechat původní kontrolky a spodní ukazatele. Tvar a barvy schváleného návrhu zachovat, přizpůsobit regionům nativního panelu.
3. UI propojit se skutečným stavem rendereru; BC z UI i páčky. Žádné ukázkové hodnoty v běhu na autě. Titul LCI Budíky a autor Vytvořeno Davidem My (330e).
4. Připravit čistý source repo: vlastní app id, vlastní GitHub zdroj, licence a kredity. Bez SDK, firmware, záznamů vozidla, přístupů nebo původního BMW fontu. Inter použít i pro generované clusterové texty.
5. Hostitelské testy životního cyklu, limitů, BC, TTL, shaderů, sestavení a manifestu. Závěrečný nezávislý přezkum.
6. Teprve potom Davidovo přihlášení GitHub, vytvoření jeho repozitáře a publikace. První test v autě není potvrzením vhodnosti za jízdy.

Ruling: První automobilový balíček bude parked-only 60 s, protože dosud není ve 330e ověřeno umístění výřezů nové grafiky. Náhled MGU je hostitelský App Kit, nikoli firmware VM.
